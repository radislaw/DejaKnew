# Product Roadmap: Flash Cards / DéjàKnew Ecosystem

> Персонализированная RPG-экосистема обучения с ИИ-тьютором, социальными механиками и глубокой кастомизацией. Монетизация: плати деньгами (быстро) или временем и усердием (валюта за обучение).

---

## Фаза 0: Фундамент (MVP)

| Задача | Описание |
| :--- | :--- |
| **Аккаунты и синхронизация** | Регистрация/вход через email, Google, Apple. Облачное хранение прогресса. |
| **Базовая работа с карточками** | Создание, редактирование, удаление, импорт/экспорт (CSV, Anki). |
| **Режим обучения** | Интервальные повторения (Spaced Repetition). Базовый алгоритм. |
| **Оффлайн-поддержка** | PWA service worker. Синхронизация при восстановлении сети. |
| **i18n-архитектура** | Базовая локализация (ru/en) с поддержкой расширения. |
| **Аналитика (MVP)** | Простые метрики: изучено карточек, время обучения, серии дней. |
| **A/B testing framework** | Необходим до Phase 2 монетизации для принятия решений на данных. |
| **Платёжный шлюз** | Stripe (web) + RevenueCat (iOS / Android). Планируются нативные мобильные версии. |
| **GDPR / приватность** | Data retention policy, право на удаление, обработка чувствительных данных (ADHD self-identification). |
| **Push-уведомления** | Инфраструктура стрик-удержания. |
| **WebSocket-инфраструктура** | Заложить в архитектуру Go-бэкенда — необходимо для Phase 4 (Silent Rooms). |
| **Онбординг flow** | Определяет activation rate. Выбор режима (обычный / фокус), первая колода. |
| **Админ-панель (MVP)** | Управление пользователями, ручная модерация. Планировать автоматизацию к Phase 4. |
| **Настройки профиля** | Ручной выбор OAuth-провайдера (Google / Яндекс), смена email, смена пароля, удаление аккаунта (GDPR). Яндекс сейчас определяется по IP — в профиле можно переопределить. |

## Фаза 1: Внутриигровая экономика и система наград

*Запускаем «двигатель вовлечения». Все функции этой фазы — бесплатны.*

### 1.1 Валюта («Нейроны» 🧠)

**Источники получения:**

| Источник | Механика |
| :--- | :--- |
| **Сеансы обучения** | Награда за результативность: правильные ответы, серии без ошибок, завершение дневной цели. |
| **Ежедневные сундуки** | Обычный (день 1–2), Редкий (день 3–5), Эпический (день 7+). С анимацией открытия. |
| **Достижения** | Единоразовая награда: «100 карточек изучено», «Идеальная неделя», «Первый курс пройден». |
| **Rewarded реклама** | Пользователь сам выбирает посмотреть видео для получения бонуса. Никаких баннеров. |

**Расходование валюты:**
- Покупка скинов и персонажей в Магазине.

### 1.2 Магазин персонажей и скинов

- **За Нейроны** (заработанные).
- **За реальные деньги** (для нетерпеливых).
- **Эксклюзивные предметы** только из сундуков (не продаются).

### 1.3 Геймификация (СДВГ-friendly по умолчанию)

- **Мгновенный микро-фидбек** на каждый правильный ответ (анимация + звук).
- **Визуализация времени:** награды показывают примерное время на получение (≈5 мин → 10 нейронов).
- **Streak Freeze:** пропуск дня замораживает серию на 24 часа. Мягкое уведомление вместо наказания.

## Фаза 2: ИИ-генерация и подписка

*Основной источник регулярного дохода.*

### 2.1 ИИ-генерация карточек

- Пользователь вводит тему / ключевые слова.
- ИИ генерирует набор карточек.
- Обязательно: редактирование перед сохранением.
- Обязательно: оценка 👍/👎 для улучшения промптов.

### 2.2 Freemium-модель ИИ

> **Двойной лимит:** per-deck (5) И per-user/month (20). Оба счётчика видны пользователю.
> Per-deck создаёт осознанное трение («подумай, прежде чем генерировать»). Monthly — глобальный потолок против злоупотреблений. Первым срабатывает тот, что исчерпан раньше.

| Уровень | Лимит |
| :--- | :--- |
| **Бесплатно** | 5 генераций на колоду + 20 генераций в месяц суммарно. |
| **Доп. генерации за валюту** | +5 на конкретную колоду **или** +10 к месячному пулу за X нейронов. |
| **Подписка** | Безлимитная генерация (оба лимита сняты). |

### 2.3 Подписка (MVP)

- **Что входит:** безлимитная ИИ-генерация, отключение рекламы.
- **Экран подписки:** простое сравнение тарифов.
- **Управление:** экран с информацией и возможностью отмены.

## Фаза 3: Интерактивная платформа курсов

*Ключевой контентный актив и второй драйвер подписки.*

### 3.1 Структура интерактивного урока

```json
{
  "lesson_id": "git-basics-01",
  "blocks": [
    { "type": "text",      "content": "## Что такое Git?..." },
    { "type": "editor",    "language": "bash", "default_code": "git init" },
    { "type": "preview",   "sandbox": true },
    { "type": "quiz",      "question": "...", "options": [...], "answer": 1 },
    { "type": "joke",      "condition": {"locale": "ru"}, "content": "О, поздравляю..." },
    { "type": "reactions", "enabled": ["laugh", "think", "fire", "sick"] }
  ]
}
```

> **Примечание по joke-блокам:** i18n должна быть заложена в Phase 0. Joke-блоки с условиями по ОС/языку требуют полноценной локализационной архитектуры.

| Тип блока | Описание |
| :--- | :--- |
| **text** | Markdown с форматированием. |
| **editor** | Monaco Editor. |
| **preview** | Песочница (WebContainers / iframe sandbox). |
| **quiz** | Проверка понимания. |
| **joke** | Условный блок (по локали, выбору пользователя). |
| **reactions** | Смайлики-реакции на блок. |

### 3.2 Курсо-ориентированные колоды

- При старте курса автоматически создаётся колода.
- Карточки (ручные или через ИИ) попадают в колоду курса.

### 3.3 ИИ-ассистент в уроках

- Кнопка «Сгенерировать карточки по этому уроку».
- Соблюдает monthly лимит свободного пользователя.

### 3.4 Freemium-доступ к курсам

| Уровень | Доступ |
| :--- | :--- |
| **Бесплатно** | Первые 5 уроков любого курса. |
| **За валюту** | Полный курс за X нейронов (эквивалент ~1–2 недель активного обучения). |
| **Подписка** | Все курсы открыты полностью. |

### 3.5 Focus Mode MVP (параллельно с Phase 3)

*Только базовые изменения — не трогает глобальную навигацию:*
- Микро-сессии по умолчанию (5–10 мин).
- Сниженные ежедневные цели.
- Без негативного фидбека на ошибки.

Полный Focus Mode (глобальный UI) — отдельный milestone после Phase 3 релиза.

## Фаза 4: Социальные механики и реакции

*Требует WebSocket-инфраструктуры, заложенной в Phase 0.*

### 4.1 Реакции на уроки

- Привязка: `user_id → block_id → reaction_type`.
- Другие пользователи видят только агрегированные счётчики (анонимно).
- 3 основных реакции на виду, остальные — по длинному нажатию.

### 4.2 Аналитика контента для команды курсов

- Блок с 80% 🤮 → упростить материал.
- Шутка с 95% 😂 → успешный Tone of Voice.

### 4.3 Социальные «Тихие комнаты» (Silent Rooms)

- **Без видео и аудио.** Только аватарки и общий таймер.
- Выбор темы («Учим Python», «Английский») и подключение.
- Эффект «библиотеки» — первая итерация Body Doubling.

### 4.4 Дружеские пары (Friend System)

- Ссылка-приглашение для существующего контакта.
- Видят персонажей друг друга, общий таймер.
- Опционально: видео/аудио только для друзей.

## Фаза 5: Полный Фокус-режим (СДВГ-адаптация)

*MVP элементов уже в Phase 3. Здесь — полный UI.*

### 5.1 Активация

- Предлагается при онбординге.
- Переключатель в профиле и быстрых настройках.

### 5.2 Что меняется

| Элемент | Обычный режим | Фокус-режим |
| :--- | :--- | :--- |
| **Главный экран** | Полная навигация | 3 крупные кнопки: «Быстрый старт», «Мои курсы», «Магазин» |
| **Сессии обучения** | Стандарт | Микро-сессии 5–10 мин с визуальным таймером |
| **Ежедневные цели** | «20 карточек» | «Открыть приложение», «3 карточки» |
| **Ошибки** | Счётчик ошибок | Только «показать позже», без негатива |
| **Навигация** | Стандартная | Крупные подписанные кнопки, одно действие на экран |
| **Анимации** | Декоративные | Быстрые, функциональные |
| **Режим «Здесь и сейчас»** | Отсутствует | Блокировка уведомлений на время сессии |
| **AI-персонаж** | Косметика | Активный компаньон (Body Doubling) |

### 5.3 AI-компаньон в Фокус-режиме

- «Учится» вместе с пользователем на экране обучения.
- Мягкие напоминания при бездействии (30+ сек): «Всё в порядке? Продолжим?».
- Рефлексивные вопросы: «Ты всё ещё хочешь учиться или сделаем перерыв?».

## Фаза 6: Продвинутая экономика и AI-тьютор

*Эндгейм-механики для долгосрочного удержания.*

### 6.1 Механики персонажей

- Пассивные бонусы:
  - «Кот-программист»: +5% к получаемой валюте.
  - «Зомби-лингвист»: одна бесплатная ИИ-генерация в день.

### 6.2 AI-тьютор (адаптивное обучение)

- Анализирует ошибки и прогресс.
- Предлагает персонализированные микро-челленджи.
- Меняет тональность в зависимости от контекста.

### 6.3 Карта компетенций

- Визуальное «древо навыков» (как в RPG).
- Ветки: «Базовый синтаксис», «Команды Git», «Времена English».
- Прохождение курсов и карточек подсвечивает узлы.

### 6.4 Creator Economy

> **Требует отдельного planning milestone.** Нужны: система модерации, DMCA / авторские права, payout-система, trust & safety, стандарты качества контента. Минимум 3–6 месяцев инфраструктуры.

- Пользователи создают и публикуют курсы.
- Продажа за валюту или реальные деньги.
- Платформа берёт комиссию.

## Рекомендуемый порядок запуска

1. **Фаза 0** — фундамент (включая WebSocket-архитектуру, i18n, GDPR, A/B testing, онбординг)
2. **Фаза 1** — быстрый win, рост удержания
3. **Фаза 2** — запуск основного регулярного дохода
4. **Фаза 3** — контентная ценность + Focus Mode MVP параллельно
5. **Фаза 4** — социальные механики на базе существующей аудитории
6. **Фаза 5** — полный Focus Mode UI
7. **Фаза 6** — эндгейм при наличии большой активной базы
8. **Фаза 6+** — Creator Economy как отдельный продуктовый трек
